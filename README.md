# Lớp Học Diệu Kỳ — bản chơi thử

Đồ dùng dạy học số cho trẻ mẫu giáo 5 tuổi (kể chuyện, khám phá khoa học), do giáo viên dẫn dắt.

Repo này chỉ chứa bản build tĩnh để chạy trên GitHub Pages.

## Bài học hiện có

**Phát triển ngôn ngữ — Kể chuyện**
- Quả táo bị thất lạc
- Cô bé quàng khăn đỏ
- Trâu trắng và trâu đen

**Khám phá khoa học**
- Nổi hay chìm? (Nổi và chìm)
- Bắp cải tím đổi màu (Phép màu trong bếp)
- Hạt gạo nhảy múa (Phép màu trong bếp)
